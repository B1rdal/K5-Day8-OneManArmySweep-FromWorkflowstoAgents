## Vì sao shape này

Choose the deterministic workflow for this structured claims task. On the same 14 public claims and seeds 11, 22, 33, 44, 55, workflow, single, and orchestrator each passed 70/70 trials. Their simulated costs per success were respectively 27.86, 38.28, and 47.77 VND. The workflow needs no model call and adds no agent coordination boundary. Refund calculations remain in compute_compensation; the existing host enforces approval, ownership, per-order caps, and idempotency. This is the least autonomous architecture supported by the measured evidence.

## Có đáng đổi lấy multi-agent không

The supplied swarm passed 69/70 trials at 49.57 simulated VND per success. Its known C-002/seed-55 failure follows customer text instead of the authoritative order. The controlled verification ablation fixes that failure without changing topology: verified swarm passes 70/70, but still costs 48.72 VND per success. More agents do not add measured value here. Reconsider the workflow if a representative held-out corpus requires document interpretation or independent investigations that fixed steps cannot handle, and a bounded agent demonstrates sufficient quality improvement under the same safety checks and an agreed cost budget.

## Trace và bằng chứng

Workflow records claim-found/order-present booleans, order-scope outcome, the deterministic quote, host outcome, and final decision. Single also records model purposes and observed tool names. No student shape records raw tickets, principal identifiers, headers, parent secrets, order rows, phone numbers, addresses, item names, or internal notes. Traces are written under traces/<run_id>.json; no additional debug artifacts or stdout are emitted. A finally block flushes the safe prefix and closes the connection even when InjectedCrash propagates. The supplied scanner checks result/trace consistency and forbidden substrings; added tests also inspect captured stdout/stderr and secrets inserted directly into a ticket.

## Giới hạn

Only public synthetic data was evaluated. Hidden grading and the >=0.75 hidden threshold remain unverified because student_drop/ and instructor labels were not supplied. MockLLM is not a production model; the single-agent adapter chooses structured read actions in Python because MockLLM returns text rather than tool calls. Workflow uses zero model calls. Costs include the budgeted read/model calls, following the supplied swarm accounting, and exclude the common host write path. The architectures use different prompts and call counts, so the four-way benchmark compares implementations rather than isolating topology. Steps count trace events and are sensitive to instrumentation: the sparsely traced reference swarm's lower steps do not establish lower runtime work. Latency is unavailable. JSON evidence is generated by the tools, not edited by hand.
